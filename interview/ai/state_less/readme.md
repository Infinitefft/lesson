# 大模型为什么是无状态、无记忆的
http 无状态 一次请求，n次请求，一样的
大模型本质是基于 Transformer 的概率生成模型，每次推理只依赖当前输入token，并不会在内部长期保存用户状态，所以是无状态无记忆。

Transformer 是现在所有大语言模型LLM的核心骨架，靠注意力（attention）机制看懂上下文、理语言，让AI能流畅地聊天、写文章

文字 -> token化，注意力因子计算，推出最接近的token输出

上下文其实是通过prompt临时拼进去的，而不是模型真的记住了

怎么解决，方案如下：

- 上下文编程(Context Engineering)，把历史对话拼接prompt
- 做RAG 检索增强生成，通过Embedding检索相关内容再喂给模型
- 做Memory 管理，比如对历史做截断、摘要、压缩或向量化长期记忆

本质就是：模型不记忆，记忆在AI工程侧
