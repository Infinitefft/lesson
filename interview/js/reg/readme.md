## 判断是不是手机号
- 一个一个字符地匹配
    1
    \d 数字
    \w 字母
- {} 长度
- ^	匹配开头	/^A/ 匹配 "Apple"
- $	匹配结尾	/t$/ 匹配 "eat"
- \d	匹配数字	/\d/ 匹配 "5"
- \w	匹配字母、数字、下划线	/\w/ 匹配 "a" 或 "1"
- *	重复 0 次或多次	/lo*/ 匹配 "l", "lo", "loo"
- +	重复 1 次或多次	/lo+/ 匹配 "lo", "loo"
- ?	重复 0 次或 1 次	/colou?r/ 匹配 color 或 colour
- .	匹配除换行符外的任意字符	/a.c/ 匹配 "abc"
- test 方法  true | false 是否匹配符号
- str.match  匹配的结果
