



## 正则匹配邮箱

正则 就是用一套特定的符号规则，来描述和匹配一类字符串的通用模式。
QQ邮箱？
用户的输入是不是一个合格的邮箱？
123456@qq.com
邮箱的基本结构
XXX@XXX.XXX

- 保证了基本结构
const reg = /.+@.+\..+/;

- 限制字符 排除非法的字符
匹配字符的开始和结束
cn, com, net, org
{} 长度 2，至少 2 位，可以更多
const reg = /^[a-zA-Z0-9._-]+@[z-zA-Z0-9.-_]+\.[a-zA-Z]{2}$/;

问题 a...b@...com 仍然可以通过
.abc@xxx.com  可以通过，不可以以 .开始
// ? 表示0次或1次
const reg = /^[a-zA-Z0-9]+([._-]?[a-zA-Z0-9]+)@[a-zA-Z0-9]+([-a-zA-Z0-9]+)\.[a-zA-Z]{2}$/


## 拿硬币

最值问题，动态规划（复杂） 贪心（简单）

贪心就是每一步都选当前最优，比如找零钱 选择最大面额，图省事但不一定全局最优

动态规划会记录子问题最优解，综合得到全局最优，更稳但复杂
