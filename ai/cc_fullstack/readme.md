## 首先：思维的转变是最重要的
从写代码到做决策。
我们是架构师，代码是AI写的。一个人（opc）长期推进一个复杂系统。

claude code 出来之前，更聪明的代码补全工具，让它写函数、重构逻辑，写代码的速度特别快，核心瓶颈不在代码的速度上

## AI 全链路流程
动第一行代码之前你要想清楚什么
先搞清楚业界标杆在做什么
第一步先不要想 我要做什么
而要看 业界最好的在做什么，先理解这个领域的全貌

- 帮我梳理 dify https://dify.ai
  这个产品的核心功能模块,按类别分组,每个模块用一两句话说明他做什么

  AI给的信息不能直接信，要验证
  手动地去查阅一些文档资料

  模型管理：接入多个LLM 提供商（OpenAI、Claude、Gemini、本地模型等），统一管理API Key，模型参数、调用配额
  应用创建：用户可以创建不同类型的AI应用--聊天助手、Agent、文本生成、工作流，每个应用可以配置模型、提示词、工具。
  工作流编排：可视化拖拽界面、把多个节点（LLM调用、条件判断、代码执行、HTTP请求）串成一个工作流。
  RAG知识库：上传文档、自动切片、向量化、存储。对话时自动检索相关内容作为上下文。
  工具集成：MCP，SKILLS等
  对话与调试：完整的对话界面，支持流式响应、多轮对话

  运营功能：用量统计、日志跟踪...
