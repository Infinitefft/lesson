### 项目概述

#### 产品定位
Eify 是一个面向团队内部（20-50 人）使用的本地部署 AI Agent 平台，目标是在单人开发可承载的范围内，快速提供稳定、可用、可集成的智能应用能力。

#### 做什么（V1）
- 提供统一模型接入与基础参数管理（优先支持少量主流模型源）。
- 支持创建两类应用：聊天助手、简化 Agent。
- 提供基础 RAG 能力：文档上传、切片、向量检索、检索增强生成。
- 提供工具调用能力：以 HTTP API 工具为核心的可配置集成。
- 提供对话界面：流式响应、多轮会话、基础会话管理。
- 提供基础调试与观测：请求日志、错误日志、耗时与调用记录。
- 提供应用调用出口：内部 Web 使用 + API 调用能力。

#### 不做什么（V1 暂不支持）
- 不做可视化拖拽工作流编排（Workflow Builder）。
- 不做 MCP 协议全量支持（后续按需扩展）。
- 不做独立文本生成应用类型（由聊天/Agent 模式承载）。
- 不做复杂运营分析大盘与商业化计费体系。
- 不做多租户隔离，采用单租户内部部署模式。
- 不做细粒度复杂权限体系，仅保留精简角色模型。

#### 技术栈
- 后端：Spring Boot（Java），提供应用管理、模型调用编排、RAG 与工具执行 API。
- 前端：Vue（建议 Vue 3 + TypeScript），提供应用配置台与对话交互界面。
- 存储（建议）：PostgreSQL（业务数据）+ Redis（会话/缓存）+ 向量库（按部署条件选型）。
- 部署：本地/内网环境部署，优先 Docker 化，确保可维护与可迁移。

    架构师每天干什么?

    1. 他不写具体的业务代码，但他决定了系统长什么样。
    2. 他定方向：做什么、不做什么。
    3. 他做取舍：遇到矛盾选 A 还是选 B。
    4. 他立标准：代码怎么写、接口怎么定、出了错怎么处理。
    5. 他验收成果：团队交付的东西是不是他要的。

    工程团队在干什么？
    在按标准高效执行。
    你给 Claude Code 下达的每一条指令，本质上就是架构师在给团队派任务
